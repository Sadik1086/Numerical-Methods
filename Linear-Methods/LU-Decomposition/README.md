
    Method: LU Decomposition using Doolittle's Method

    Description:
    This program solves a system of linear equations using
    LU Decomposition by Doolittle's Method.

    Input:
    - An integer n representing the number of equations.
    - An n × (n+1) augmented matrix.

    Output:
    - Lower triangular matrix L.
    - Upper triangular matrix U.
    - Type of solution: Unique, Infinite, or No Solution.
    - Variable values for a unique solution.
    - Verification of the obtained solution.
